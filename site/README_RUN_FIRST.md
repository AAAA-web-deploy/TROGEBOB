## Start in under 30 seconds

Unzip. Open the `site` directory in Cursor. Open `site/index.html` in a browser, **or** run a local static server:

```bash
cd site
python -m http.server 4173
```

Then visit http://localhost:4173. No npm, no npm install, no build step, no Node requirement, no APIs, no credentials.

For Windows, double-click `START_LOCAL_SITE_WINDOWS.bat` at the package root (Python must be on PATH).

**Cursor instructions:** See `CURSOR_ZERO_TO_COMPLETE.md` in the package root. This instruction file explicitly supports an entirely EMPTY directory / missing source-code situation. It does NOT depend on any former TROGEBOB or $3OR1 project.
